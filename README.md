# Coffee Corner Order Management System

A simple console-based Coffee Shop Order Management System developed in C++ using Singly Linked List.

--------------------------------------------------

FEATURES

- Place New Orders
- Display All Orders
- View Waiting Orders
- Complete Orders
- Remove Orders
- Dynamic Memory Allocation
- Menu Driven Interface

--------------------------------------------------

DATA STRUCTURE USED

Singly Linked List

Each customer order is stored as a node in the linked list.

Advantages:
- Dynamic size
- Easy insertion and deletion
- Efficient memory usage

FUNCTIONALITIES

1. Place Order
   Adds a new customer order.

2. Show All Orders
   Displays all orders with status.

3. Waiting Orders
   Displays only pending orders.

4. Complete Order
   Marks an order as completed.

5. Remove Order
   Deletes an order from the linked list.
